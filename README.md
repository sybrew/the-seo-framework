# [The SEO Framework](https://theseoframework.com) #

![The SEO Framework Banner](.github/assets/banner-1544x500.png)

The SEO Framework is a free WordPress SEO plugin by Sybre Waaijer. It generates search and social metadata from each page's content. The output follows documented search engine rules. The WordPress dashboard has no ads, nags, or plugin branding.

This repository is the source. [WordPress.org](https://wordpress.org/plugins/autodescription/) ships the stable releases.

Optional extensions ship through the free [Extension Manager](https://theseoframework.com/?p=2760). [Pricing](https://theseoframework.com/pricing/) lists the paid plans for extra sites, API quota, and private support.

## Troy and Composer ##

If you already run [Troy Client](https://kb.theseoframework.com/kb/what-is-troy-client/), this plugin updates from `repo.theseoframework.com`. WordPress.org installs do not need Troy Client.

Composer can require this repository as [`sybrew/the-seo-framework`](https://packagist.org/packages/sybrew/the-seo-framework). Pin a release tag for production.

A [Troy Composer repository](https://deploytroy.org/docs/troy-server/composer/) also serves the built plugin at `https://repo.theseoframework.com/composer/get`. Setup is in the [install guide](https://kb.theseoframework.com/kb/how-to-install-the-extension-manager/#install-composer).
