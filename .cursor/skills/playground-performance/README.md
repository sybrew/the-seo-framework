# Playground hotspot profiling

Use the [hotspot profiling skill](../../../.claude/skills/playground-performance/SKILL.md). From the repository root, run the shared dispatcher with the operation you need:

```text
node .claude/skills/playground-performance/scripts/performance.js --help
```

Use `run` for timing, `export` for saved data, and `test` for the shared engine's synthetic checks.
